Installation

Trois étapes, et rien à configurer.

Lancez l'installeur

Ouvrez le fichier téléchargé. Windows peut afficher un avertissement SmartScreen sur une application récente : choisissez « Informations complémentaires », puis « Exécuter quand même ».

Collez votre clé

La clé de licence reçue par courriel se colle une fois, au premier lancement. Il n'y a ni compte à créer, ni mot de passe, ni assistant de configuration à traverser.

Réglez vos seuils

Dans le panneau Paramètres, ajustez si besoin le reliquat de jours, le seuil d'interruption et la fenêtre du sinistre non impacté. Les valeurs par défaut conviennent à la plupart des pratiques.

Configuration requise

Ce qu'il faut sur le poste.

  • Windows 10 ou Windows 11, en 64 bits.
  • WebView2, déjà présent sur ces versions de Windows : rien à installer en plus dans la quasi-totalité des cas.
  • Aucune connexion Internet n'est nécessaire au fonctionnement.
  • Ni macOS ni Linux pour l'instant. Écrivez-nous si c'est un besoin pour vous.
Avertissement SmartScreen

Windows signale toute application dont la réputation n'est pas encore établie, indépendamment de son contenu. L'installeur est signé et distribué depuis ce site uniquement : ne le téléchargez pas ailleurs.

Plusieurs postes à équiper ?

Il n'existe pas encore d'offre multi-postes. Si vous devez équiper plusieurs gestionnaires, écrivez-nous : c'est ce genre de demande qui décide de ce que nous construisons ensuite.
